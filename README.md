# 那須 2泊3日 旅行計画（2026年10月 ／ 出発日5パターン）

梗華の誕生日・粧子の誕生日・結婚20周年を兼ねた那須旅行の計画ページ。
出発日を **10/9・10/10・10/16・10/23・10/30** の5パターンで切り替えて比較できます。

**公開URL** → https://dat0925.github.io/nasu-trip-2026/

## 出発日

すべて2泊3日。10/10発だけが3連休（10/10〜10/12）を使う土曜発で、ほかの4日程は金曜発です。

| 出発日 | 日程 | 性格 | A案 実費 |
|---|---|---|---|
| 10/9（金） | 10/9〜10/11 | 最安。10/12（月・祝）が予備日として残る | 149,200円 |
| 10/10（土） | 10/10〜10/12 | **実地調査済みの確定値**。休みを取らずに行ける唯一の日程 | 159,355円 |
| 10/16（金） | 10/16〜10/18 | 連休も紅葉ピークも外した通常週末。混雑が最小 | 152,100円 |
| 10/23（金） | 10/23〜10/25 | 那須高原の紅葉ピーク。宿代は最高 | 156,900円 |
| 10/30（金） | 10/30〜11/1 | 10/31がハロウィン。麓の紅葉が見頃 | 153,000円 |

A案＝ねむりん＋サンバレー那須／B案＝ねむりん＋エピナール那須（＋約2万円）。

## 内容

- 1泊目：ペンション合歓林（ねむりん）オリエンタル ─ 各予約サイトを横断して最安プランを特定
- 2泊目：ホテル三日月級のビュッフェ宿を2案比較（サンバレー那須 / エピナール那須）
- 那須ハイランドパーク・那須とりっくあーとぴあ・トレジャーストーンパークの実費
- 出発日ごとの紅葉・混雑・空室見込みとメリット／注意点
- 3日間のタイムライン
- 予算シミュレーション（目標15万 / 上限20万）
- 公式サイト・予約サイト・Instagram のリンク集

## 前提

- 大人2名 ＋ 小学3年生1名（じゃらん「小学生」区分）／1室
- 価格はすべて税込総額。調査日は 2026年8月28日
- **10/10（土）発の宿泊料だけが実測値**。ほかの4日程は曜日係数（金曜泊0.80／土曜泊1.00／連休中日1.06）と
  紅葉シーズン係数（1.00〜1.08）から算出した**推定値**です。根拠は `compare.html` の「推定の根拠」に記載
- 宿泊料以外の6項目（ステーキ・那須ハイ・とりっくあーと・トレジャー・交通費・食事＆お土産）は
  全日程共通の **61,000円**。出発日で動くのは宿泊料だけです
- 料金・空室は変動するため、予約前に各サイトで要確認

## 金額の更新

実際の見積りが出たら `data.js` の `rates`（`nemurin` / `sunvalley` / `epinard`）を書き換えるだけで、
クーポン・ポイント・合計・グラフ・明細表がすべて自動で再計算されます。
`epinard` は早期割引を**適用する前**の通常料金を入れてください。

```js
{ id:'1016', ..., rates:{ nemurin:37100, sunvalley:62000, epinard:88700 }, ... }
```
