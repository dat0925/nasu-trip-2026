## 内容

- 1泊目：ペンション合歓林（ねむりん）オリエンタル ─ 各予約サイトを横断して最安プランを特定
- 2泊目：ホテル三日月級のビュッフェ宿を2案比較（サンバレー那須 / エピナール那須）
- 那須ハイランドパーク・那須とりっくあーとぴあ・トレジャーストーンパークの実費
- 出発日ごとの紅葉・混雑・空室見込みとメリット／注意点
- 3日間のタイムライン
- 予算シミュレーション（目標15万 / 上限20万）
- 公式サイト・予約サイト・Instagram のリンク集

## 調査して分かったこと

- **宿は連休以外どこも同額。** ねむりんは 10/10泊だけ45,000円で、残り5泊はすべて34,000円。
  サンバレーも 10/10泊 69,795円・10/11泊 63,855円に対し、他の4泊はすべて51,975円。
  曜日や紅葉で細かく動くのではなく、3連休かどうかだけで決まっていました。
- **連休の2日程はサンバレーのクーポンが出ていません。** 他の4日程には11,000円分。これが差をさらに広げます。
- **じゃらんポイントの還元率が日程で激変。** 10/16泊までは12%、10/17〜10/31泊は2%、
  サンバレー 11/7泊だけ15%。実費が同じ127,175円でも実質は最大6,758円変わります。
- **B案（エピナール絆＋早割42）が取れるのは4日程だけ。** 10/24泊と11/7泊はほぼ満室で、
  2食付きは「部屋おまかせ・夕食遅め」の訳ありプランしか残っていません。
- **ボトルネックは常にねむりん。** 全日程で残1〜2室です。

## 前提

- 大人2名 ＋ 小学3年生1名（じゃらん「小学生」区分）／1室
- 価格はすべて税込総額。調査は 2026年8月28日 20:00
- 宿泊料は**6日程すべて実測値**です。じゃらんnet で日付を指定し、大人2名＋小学生1名・1室で
  実際に出てきたプラン・料金・クーポン・ポイント・残室数を取得しています（計18通り）。
  推定や按分は使っていません。方法は `compare.html` の「調査方法」に記載
- 宿泊料以外の6項目（ステーキ・那須ハイ・とりっくあーと・トレジャー・交通費・食事＆お土産）は
  全日程共通の **61,000円**。出発日で動くのは宿泊料だけです
- 料金・空室は変動するため、予約前に各サイトで要確認

## 金額の更新

再調査したら `data.js` の `stay` を書き換えるだけで、支払額・ポイント・合計・グラフ・明細表が
すべて自動で再計算されます。`price` はじゃらん表示額（クーポン適用前）、`coupon` はその部屋で
取得できるクーポンの合計、`point` は画面の「加算予定ポイント」をそのまま入れてください。

```js
stay:{
  nemurin:{ date:'10/16（金）泊', price:34000, coupon:8800, point:4080, stock:1,
            plan:'ノンアルコール基本プラン', room:'別館 ツインルーム【禁煙】' },
  ...
}
```
